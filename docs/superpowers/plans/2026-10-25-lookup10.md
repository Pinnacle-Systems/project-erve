# LOOKUP-10 Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Discover inventory-backed Dispatch Order Styles in bounded pages while independently hydrating complete selected-Style pools.

**Architecture:** Parameterized PostgreSQL aggregation evaluates Factory/search and effective positive Size availability before stable Style Number/ID keyset pagination. A separate infinite-query lookup owns discovery; deduplicated Factory/Style/exclusion queries own selected quantities. Extend LookupField with optional keyboard-accessible panel actions, preserving existing consumers.

**Tech Stack:** Express, Prisma/PostgreSQL, Zod, React, TanStack Query, Vitest.

**Spec:** User-provided Phase B LOOKUP-10 specification (approved Phase A); retained in this session's attachment. Implementation through PR creation is explicitly authorized without routine approval.
